# 技术架构

采用单进程 FastAPI 服务和无构建步骤的原生 Web 前端，降低 2 核、1M 带宽服务器的部署与运行成本。API、用户端和管理员端同源交付，Nginx 只代理独立路径 `/resume-ai/`。

业务数据以小粒度 JSON 对象写入 TOS-A，避免服务器数据库持久化；原始简历与生成文件写入 TOS-B；图片与 OCR 素材写入 TOS-C。下载使用短期签名 TOS URL，文件流量不经过应用服务器。对象键包含用户 ID，服务端在每个资源接口校验所有权。

SenseNova 适配层使用 OpenAI 兼容接口。预处理、简历改写和图像生成由固定模型承担，统一接入并发信号量、最小调用间隔、指数退避重试和模型调用计数。AI 不可用时返回可诊断错误，不伪造成功结果。

部署脚本创建独立虚拟环境、自动探测空闲端口、安装专属 systemd 服务并以独立 Nginx snippet 接入现有站点。脚本不覆盖现有项目目录、容器、数据库或完整 Nginx 配置。
