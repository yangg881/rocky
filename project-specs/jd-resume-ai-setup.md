# 多用户 AI 岗位 JD 简历适配系统规格

本项目实现用户注册登录、三类基础简历录入、三类 JD 提交、SenseNova 三模型流水线、忠于事实的简历改写、Word/PDF 导出、个人历史、独立管理员后台、三类 TOS 存储、用量预警、自动端口探测与一键部署。

## 强制边界

- 服务器只保留源码和运行环境，业务数据、文件、图片与审计记录写入 TOS。
- A、B、C 三个 Bucket 分别承载系统数据、简历文件、图片素材，不复用其他项目对象前缀。
- 普通用户数据按用户 ID 隔离，所有读写接口在服务端校验所有权。
- SenseNova 统一使用 `https://token.sensenova.cn/v1` 和 Bearer API Key。
- 改写模型不得编造经历，只允许排序、关键词对齐、表述和重点优化。
- 部署目录、systemd 服务、端口和 Nginx 路径均与同机项目隔离。

## 验收范围

健康检查、注册、登录、重置密码、修改密码、简历新建/上传/OCR/编辑/重命名/默认/删除、JD 文本/URL/图片解析、AI 改写、Word/PDF 生成、TOS 直连下载、个人历史、管理员用户与记录管理、模型统计、TOS 仪表盘、自动端口、一键部署和线上冒烟测试。
